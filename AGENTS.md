# AGENTS.md

## Vision

Vane is an always-on assistant that lives in one chat that never ends. Instead of a
session that fills up and gets dropped, vane keeps a single persistent
conversation backed by [UniiChat](https://gist.github.com/VictorTaelin/91837951a5ce5b38f341ec1ba1df6449):
every message is logged forever, compressed into a tree of summaries, and recalled
by zooming, so the context stays small and nothing is lost.

The same conversation is reachable from multiple platforms (Discord today, more
later), talks in whatever chat it was addressed from, and reaches for agent tools
when work is big enough to hand off. It runs unattended on a server and is there
whenever you message it.
